# Vehicle and rail settings

Copy the Vehicles and Rails folders into server Mods/UserCode with the matching Railworks DLL and bundle. Preserve customized files on upgrades, add missing files, edit constants and restart Eco. Keep filenames, namespaces, class names and keys intact. Eco compiles these configuration files; no SDK build is required.

Vehicles contains fourteen files for capacities, mass, speed and other vehicle options. Rails contains eight files for track-specific options. LargeCargoCar allows dumping by default; set AllowDumping to false to opt out. A server restart applies edits.
