# Railworks Workshop - Coaster Camera

Optional client-side BepInEx plugin that adds an improved camera experience when riding rollercoasters.

### Installation
Requires **BepInEx 6 IL2CPP** (tested with Windows x64 bleeding-edge build 788).

Extract the DLL from the ZIP into:
`BepInEx/plugins/Eco.Railcraft.CoasterCamera.Client.dll`

### Controls
**Shift + F9** - Toggle the coaster camera on/off.
